Mechanics of Materials
Normal Stress
σ = F / A
σ = stress (Pa), F = force (N), A = area (m²)
Shear Stress
τ = V·Q / (I·t)
V = shear force, Q = first moment, I = moment of inertia, t = width
Bending Stress
σ = M·c / I
M = bending moment, c = distance from NA, I = second moment of area
Hooke's Law
σ = E·ε
E = Young's modulus, ε = strain (dimensionless)
von Mises Criterion
σ_vm = √(σ₁²-σ₁σ₂+σ₂²)
σ₁, σ₂ = principal stresses; fail if σ_vm ≥ Sy
Factor of Safety
n = Sy / σ_allow
Sy = yield strength, σ_allow = allowable stress
Euler Column Buckling
P_cr = π²EI / (KL)²
K = end condition factor, L = length, I = min. moment of inertia
Torsional Shear
τ = T·r / J
T = torque, r = radius, J = polar moment of inertia
Thermodynamics & Heat Transfer
First Law (Closed)
ΔU = Q - W
U = internal energy, Q = heat in, W = work out
Ideal Gas Law
PV = nRT = mR_s·T
R = 8.314 J/mol·K, R_s = specific gas constant
Fourier's Law (Conduction)
Q̇ = -kA·(dT/dx)
k = thermal conductivity (W/m·K), A = area, dT/dx = gradient
Newton's Law (Convection)
Q̇ = h·A·(T_s - T_∞)
h = convection coefficient (W/m²·K)
Thermal Resistance
R_cond = L/(kA), R_conv = 1/(hA)
Series: R_tot = ΣR; Q̇ = ΔT/R_tot
LMTD (Heat Exchanger)
Q̇ = U·A·LMTD
LMTD = (ΔT₁-ΔT₂)/ln(ΔT₁/ΔT₂)
Carnot Efficiency
η_max = 1 - T_L/T_H
T_L, T_H = absolute temperatures (K)
Boiler Efficiency
η = Q_useful / Q_input = ṁ_s·h_fg / Q_fuel
h_fg = latent heat of vaporization
Fluid Mechanics
Bernoulli Equation
P + ½ρv² + ρgh = const
ρ = density, v = velocity, g = 9.81 m/s², h = elevation
Reynolds Number
Re = ρvD/μ = vD/ν
Re < 2300: laminar, >4000: turbulent, μ = dynamic viscosity
Darcy-Weisbach (Pipe Loss)
h_f = f·(L/D)·(v²/2g)
f = Darcy friction factor (from Moody chart)
Continuity Equation
ρ₁A₁v₁ = ρ₂A₂v₂
For incompressible: A₁v₁ = A₂v₂
Nusselt Number
Nu = hL/k = f(Re, Pr)
Dittus-Boelter: Nu = 0.023·Re⁰·⁸·Prⁿ (turbulent pipe)
Pump Power
P = ρgQH / η_pump
Q = flow rate (m³/s), H = head (m), η = efficiency
Pressure Vessel (ASME Thin-wall)
Hoop Stress (Cylinder)
σ_h = P·r / t
P = internal pressure, r = inner radius, t = wall thickness
Longitudinal Stress
σ_l = P·r / (2t)
Hoop always governs: σ_h = 2·σ_l
Min. Wall Thickness (ASME VIII)
t = P·R / (S·E - 0.6P)
S = allowable stress, E = joint efficiency (0.6–1.0)
Spherical Shell Stress
σ = P·r / (2t)
Uniform in all directions; more efficient than cylinder
